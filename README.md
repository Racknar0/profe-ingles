# Profe Inglés (Método *Friends*)

Sistema personal de entrenamiento vocal (Shadowing), vocabulario y gramática con *Friends*.

- **Pop-up Entrenador (Windows):** `Iniciar_Popup.bat`
- **App Web Móvil (PWA):** carpeta `web/` (`Abrir_Web_Local.bat` o GitHub Pages)
- **Base de datos:** `data/banco.json` (sincronizada con `python sync_data.py`)
